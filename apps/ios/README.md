# iPhone app

A SwiftUI app for iPhone and iPhone Duo:

- BLE pairing (Add Mac) and a list of paired Macs;
- signed status, with connectivity and session shown separately;
- an unlock-signing key that requires system-enforced Face ID, Touch ID or passcode for every authorization;
- outcome handling that never reports false success.

Not started (spec steps 3, 5, 7). See [`docs/spec.md`](../../docs/spec.md) and [`docs/design.md`](../../docs/design.md).
